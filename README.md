# AutoFish 挂机钓鱼插件

适用于 TShock 服务端的自动钓鱼插件，通过底层反射对接原版掉落规则引擎（`FishDropRules`），在服务端完整还原原版生态掉落、稀有度掷骰及特殊事件机制。

---

## 指令与权限

| 指令 | 别名 | 所需权限 | 说明 |
| --- | --- | --- | --- |
| `/autofish` | `/af` | `autofish.use` | 切换当前玩家的自动钓鱼挂机状态（开启后需手动抛竿一次启动） |
| `/autofish reload` | `/af reload` | `autofish.admin` | 重新加载插件配置文件（`AutoFish.json`） |
| `/autofish status` | `/af status` | `autofish.admin` | 查看当前服务器的原版链路命中、兜底表命中及调用失败统计 |

---

## 配置文件说明

配置文件路径：`tshock/AutoFish.json`

首次运行插件时会自动生成该文件，支持在游戏内执行 `/af reload` 热重载。

```json
{
  "入水后咬钩延迟Ticks(0为瞬间咬钩,60为1秒)": 180,
  "收杆后补抛延迟Ticks(20约0.33秒)": 120,
  "鱼饵消耗倍率(1.0为原版概率,0为不消耗,2.0为双倍消耗概率)": 1.0
}

```

| 配置项 | 默认值 | 类型 | 说明 |
| --- | --- | --- | --- |
| `BiteDelayTicks` | `180` | 整数 (Ticks) | 浮标入水后判定咬钩的等待时间（60 Ticks = 1 秒） |
| `RecastDelayTicks` | `120` | 整数 (Ticks) | 成功收杆后自动执行下一次抛竿的缓冲间隔 |
| `BaitConsumeMultiplier` | `1.0` | 浮点数 | 鱼饵消耗概率倍率。`1.0` 为原版概率，`0` 为不消耗鱼饵，`2.0` 为双倍消耗概率 |

---

## 安装与部署

1. 确保服务端运行环境为 TShock for Terraria 1.4.4+ 版本。
2. 编译项目生成 `AutoFish.dll`。
3. 将 `AutoFish.dll` 放置于服务端的 `ServerPlugins` 目录下。
4. 启动服务器，使用 TShock 权限管理系统为目标用户组分配 `autofish.use` 权限（管理员组分配 `autofish.admin`）。

---

## 运行机制与注意事项

* **熔岩与蜂蜜空竿现象**：原版岩浆与蜂蜜掉落池中不存在“普通（Common）”级别的基础白条鱼。若玩家总渔力较低或未掷中高稀有度产物，原版掉落结果为 0（空竿）属于正常机制，可通过提升渔力（垂钓药水、高渔力钓竿/鱼饵）降低空竿率。
* **熔岩垂钓前提**：在岩浆中垂钓时，玩家仍需满足原版资格（装备防熔岩渔具、使用热线钓竿或携带熔岩鱼饵），否则原版链路将不产生熔岩渔获。
* **鱼饵耗尽保护**：当玩家背包中所有有效鱼饵消耗完毕后，插件会自动停止挂机并发送系统提示，不会进行空转抛竿。
