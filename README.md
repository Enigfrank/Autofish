# AutoFish - 全自动挂机钓鱼插件

轻量级全自动钓鱼插件，支持自定义咬钩延迟、原版鱼饵消耗倍率控制、全自动循环钓鱼。插件通过反射直接调用原版 `Projectile` 类内部的钓鱼掉落链路方法，尽可能还原原版随机掉落机制

---

##  指令与权限

| 指令 | 别名 | 所需权限 | 说明 |
| --- | --- | --- | --- |
| `/autofish` | `/af` | `autofish.use` | 开启或关闭个人的自动挂机钓鱼模式 |
| `/autofish reload` | `/af reload` | `autofish.admin` | 重新加载插件配置文件 `AutoFish.json` |

> **给普通玩家分配权限示例**：
> ```text
> /group addperm default autofish.use
> ```

## 配置文件说明

插件首次加载后会在服务器 `tshock/AutoFish.json` 自动生成配置文件：

```json
{
  "入水后咬钩延迟Ticks(0为瞬间咬钩,60为1秒)": 180,
  "收杆后补抛延迟Ticks(20约0.33秒)": 120,
  "鱼饵消耗倍率(1.0为原版概率,0为不消耗,2.0为双倍消耗概率)": 1.0
}

```

### 参数详解

* **`入水后咬钩延迟Ticks(0为瞬间咬钩,60为1秒)`**（默认: `180` / 3秒）：
* 浮标接触水体/熔岩/蜂蜜后到触发咬钩的时间设为 `0` 即为入水瞬间秒咬钩


* **`收杆后补抛延迟Ticks(20约0.33秒)`**（默认: `120` / 2秒）：
* 渔获结算销毁浮标后，等待多久再次自动抛出下一竿


* **`鱼饵消耗倍率(1.0为原版概率,0为不消耗,2.0为双倍消耗概率)`**（默认: `1.0`）：
* `0.0`：完全不消耗鱼饵（无限鱼饵挂机）
* `1.0`：严格遵照原版概率公式计算（鱼饵力越高消耗概率越低）
* `2.0` 及以上：成倍提升消耗概率（上限为 100% 每次必消耗）

## 掉落机制说明

咬钩触发时，插件会依次尝试调用原版 `Projectile` 类中的以下内部方法（与原版抛竿钓鱼走的是同一套判定逻辑）：

1. `FishingCheck_RollDropLevels` —— 摇出本次垂钓命中的稀有度档位（普通/罕见/稀有/极稀有/传说/箱子）
2. `FishingCheck_ProbeForQuestFish` —— 判定是否命中渔夫任务鱼
3. `FishingCheck_RollEnemySpawns` —— 判定是否触发怪物入侵（如宝藏怪）
4. `FishingCheck_RollItemDrop` —— 最终摇出具体掉落物品

这四步全部成功匹配时，掉落结果与手动抛竿钓鱼完全一致（含任务鱼、稀有鱼、各类箱子等）。

**兜底机制**：由于这些是游戏内部私有方法，不同的 OTAPI/Terraria 构建版本可能导致方法名或签名对不上。若反射匹配失败，插件会自动切换到内置的简化掉落表（按生物群落粗略模拟常见鱼类/箱子），保证插件不会崩溃或停止工作，但此时掉落分布只是近似值，无法完全等同原版。

**如何确认当前是否命中原版逻辑**：插件启动时会在服务器控制台打印一行日志，形如：

```text
[AutoFish] 原版钓鱼方法反射结果: RollDropLevels=True ProbeForQuestFish=True RollEnemySpawns=True RollItemDrop=True
```

四项均为 `True` 表示成功接入原版掉落逻辑；只要有一项为 `False`，控制台会额外打印一条错误提示，说明当前会话使用的是兜底掉落表。如果长期看到 `False`，通常是服务端 OTAPI/Terraria 版本与本插件适配的方法签名不一致，需要用反编译工具（如 dnSpy/ILSpy）核对服务端程序集里 `Projectile` 类的实际私有方法名和参数类型后调整插件源码。

## 使用方法

1. 进入服务器，手持任意钓竿，确保背包内备有鱼饵
2. 在聊天框输入 `/af` 开启挂机钓鱼模式
3. 对准目标水域**手动正常抛竿一次**
4. 插件捕获抛竿参数后，即会进入「自动咬钩 $\rightarrow$ 自动收杆结算 $\rightarrow$ 自动补抛」的循环
5. 再次输入 `/af` 或切换手持物品即可停止/暂停挂机

## 构建与安装

* **运行环境**：.NET 9.0 SDK
* **依赖程序集**：
* `OTAPI.dll`
* `TerrariaServer.dll`
* `TShockAPI.dll`


* **部署路径**：编译生成的 `AutoFish.dll` 放置于服务端的 `ServerPlugins/` 目录下即可
